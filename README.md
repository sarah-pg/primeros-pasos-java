# Primeros Pasos en Java

Repositorio dedicado a los primeros ejercicios prácticos de programación desarrollados durante el primer bloque del ciclo de Desarrollo de Aplicaciones Web (1º de DAW).

## Contenidos del proyecto
* **Estructuras condicionales:** Control de flujos utilizando bloques `if-else` y operaciones aritméticas.
* **Menús interactivos:** Implementación de un menú de opciones por consola utilizando la estructura `switch`.
* **Interacción con el usuario:** Uso de la clase `Scanner` para la lectura y gestión de datos introducidos a través del teclado.

## Tecnologías utilizadas
* **Lenguaje:** Java 
* **Entorno de desarrollo (IDE):** NetBeans
