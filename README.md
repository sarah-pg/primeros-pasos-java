# Primeros Pasos en Java

Repositorio dedicado a los primeros ejercicios prácticos de programación desarrollados durante el primer bloque del ciclo de Desarrollo de Aplicaciones Web (1º de DAW).

## Contenidos del proyecto

- **Estructuras condicionales:** Control de flujos utilizando bloques `if-else` y operaciones aritméticas.
- **Estructuras de repetición (Bucles):** Prácticas con `for`, `while` y `do-while` para la iteración y filtrado numérico entre rangos definidos por teclado.
- **Menús interactivos:** Implementación de menús de opciones por consola utilizando la estructura `switch`.
- **Interacción con el usuario:** Uso de la clase `Scanner` para la lectura y gestión de datos introducidos a través del teclado.

## Estructura de archivos

- `MiPrimerProyecto.java`: Primeros ejercicios básicos de toma de decisiones y menú de contactos base.
- `Ejemplosbucles.java`: Colección de ejercicios prácticos enfocados en el uso y control de bucles.

## Tecnologías utilizadas

- **Lenguaje:** Java
- **Entorno de desarrollo (IDE):** NetBeans
